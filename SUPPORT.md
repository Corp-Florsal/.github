# Support

## Scope

This organization contains corporate platforms, products, educational programs, internal systems and client solutions.

## Where to ask for help

- Use a repository issue for reproducible bugs, feature requests or documentation problems.
- Use repository discussions when enabled for general questions and ideas.
- Do not post passwords, API keys, client data, payroll data, invoices or personal information.

## Response priority

1. Security and data exposure.
2. Production interruption.
3. Financial or workflow integrity.
4. Functional defects.
5. Documentation and enhancement requests.

## Service expectations

Unless a written client agreement states otherwise, repositories are maintained on a best-effort basis and do not include guaranteed response or resolution times.

## Paid support

Paid support or external infrastructure must not be activated without approval from the organization owner and a documented recurring cost.
