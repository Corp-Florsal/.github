## Safety rules

- Do not delete repositories during reorganization.
- Do not overwrite folders with the same name.
- Do not move repositories with uncommitted changes before review.
- Do not force push.
- Do not rewrite Git history.
- Verify `origin`, branch and working tree after every move.
- Pull from the current remote only after confirming that the remote matches the official GitHub location.

## Validation checklist

For each repository confirm:

- Local folder name matches repository name.
- Remote owner and repository name are current.
- Current branch is intentional.
- Working tree is clean or changes are documented.
- Local branch is not unexpectedly ahead or behind.
- README exists.
- Repository is stored under the correct local classification.
