# Corp-FlorSal

**Holding de administración y desarrollo.**  
Construimos soluciones móviles y backend para gestión empresarial.

## Líneas
- **Mobile** (Android, Kotlin/Java)
- **Backend** (Java/Spring o Node)
- **Data & Automation**
- **DevOps/Infra** (CI/CD, IaC)

## Repositorios
- `msd-android` — app Android (MSD_MA)
- `msd-backend` — API
- `msd-infra` — pipelines, IaC (GitHub Actions/Terraform)
- `msd-shared` — libs compartidas

## Estándares
- PRs obligatorios a `main`
- CI: build + test + lint
- Versionado semántico y CHANGELOG
